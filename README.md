# Ramakos Customer Feedback & Suggestions

> **Customer Feedback & Review Portal** for **Ramakos Catering Service** (Kumasi Branch).  
> *"good food, good taste"* — Phone: `+233 32 249 6812`

---

## 1. Overview

**Ramakos Customer Feedback** is the customer-facing feedback application accessible via table QR codes and online links. It empowers diners to submit reviews, compliments, and service suggestions directly to the Ramakos Executive Command Center.

---

## 2. Key Features

- **Star Rating & Categorization**: Rate food quality, customer service, and cleanliness; categorize as Suggestion or Complaint.
- **Image & Receipt Attachment**: Upload photos to substantiate feedback.
- **Direct HQ Pipeline**: Submissions stream instantly to the Command Center Feedback Inbox.

---

## 3. Technology Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Backend**: [Supabase](https://supabase.com/)

---

## 4. Local Development

```bash
# 1. Navigate to directory
cd customer-suggestion

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```
